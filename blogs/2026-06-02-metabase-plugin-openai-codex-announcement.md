Metabase is now available as a plugin in ChatGPT and OpenAI's Codex, letting users connect their Metabase instance directly to ask questions, find insights, and create dashboards using natural language. The integration leverages Metabase's semantic layer to deliver data-driven answers grounded in actual company data without leaving the workflow.
